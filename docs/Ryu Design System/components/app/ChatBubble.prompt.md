Mensagem do chat. A tela de Chat é a única que usa a escala **neutral** em vez de **zinc** — mantenha assim para fidelidade.

```jsx
<ChatBubble role="user" time="14:02">Rode os testes do runner</ChatBubble>
<ChatBubble role="agent" time="14:02">Rodando pytest…</ChatBubble>
<ChatBubble typing>agente digitando…</ChatBubble>
```
