Card de agente.

```jsx
<AgentCard name="Codebot" handle="codebot" runtime="claude" status="working" description="Corrige bugs do backend" />
<AgentCard compact name="Reviewer" handle="reviewer" runtime="codex" status="idle" />
```

O handle sempre aparece com `@`; runtime é o valor cru (`claude`, `codex`, `gemini`).
